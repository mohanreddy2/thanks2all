A diary of thanks

I write short notes the way I would write in a notebook. After I connect a Google Form and Sheet, each new response appears here. Until then, the first chapters of the journey are below.

How I add a daily update (Google tools)

  1. Open Google Forms with mohan.reddy02@gmail.com. Title it “thanks2all daily note”.
  2. Add three questions: Date (Date), Title (Short answer), Note (Paragraph).
  3. Responses → Link to Google Sheets. In the Sheet: File → Share → Publish to web → choose the sheet → CSV. Copy that CSV link.
  4. Paste the CSV link into js/diary-config.js as sheetCsv. Optional: Form → Send → Embed → paste the iframe URL as formEmbed.

After that, a new Form row is a new diary page. No website rebuild needed for each note — only the first config save.
