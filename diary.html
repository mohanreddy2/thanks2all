How to connect Form and Sheet once
  1. Open Google Forms. Create “thanks2all daily note” with Date, Title, and Note.
  2. Responses → Link to Sheets. That creates the Google Sheet.
  3. In the Sheet: Share → Anyone with the link → Viewer (or Editor if they should type). Copy the link.
  4. Optional: File → Share → Publish to web → CSV, and Embed, so this page can show the table.
  5. Paste those links in the admin (Form embed / Form share / Sheet CSV / Sheet share / Sheet embed) and save.
